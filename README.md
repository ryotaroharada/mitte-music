3. **コンセプト** - 「すべての年代に」「独自カリキュラム」「音楽を楽しむ心」
4. **コース案内** - 4コース（ピアノ・ソルフェージュ・チェロ・コントラバス）
5. **講師紹介** - プロフィール未登録（写真プレースホルダー）

8. **アクセス** - 住所＋Google Maps枠
9. **お問い合わせフォーム** - 体験レッスン申し込み対応
10. **お知らせ** - ニュース一覧
11. **フッター** - サイトマップ＋コピーライト

## 次回やること

### 高優先度
- [ ] **お問い合わせフォームの動作設定**
  - Formspree (https://formspree.io) に登録
  - `script.js` 内の `formspree.io/f/your-form-id` を実際のIDに書き換える
- [ ] **講師プロフィールの作成**
  - `index.html` の講師紹介セクションを編集
  - 講師写真を `instructor-img` に設定
- [ ] **ギャラリー写真の差し替え**
  - `gallery-item` の背景色・テキストを実際の写真に置き換え


### 低優先度
- [ ] SNSアカウント（Instagram / X）のリンク設定
- [ ] お知らせ記事の追加
- [ ] 独自ドメインの設定（お持ちの場合）

## デプロイフロー
